วงจรที่ 1

วงจรไฟหรี่ (Dimmer Circuit)

ใช้งานตัวต้านทานปรับค่าได้ (Potentiometer) ร่วมกับหลอดไฟ เพื่อควบคุมระดับความสว่างในวงจรไฟฟ้า

ประโยชน์ของวงจร

  • ช่วยประหยัดพลังงานไฟฟ้าโดยการลดความสว่าง
  • ยืดอายุการใช้งานของหลอดไฟให้อยู่นานขึ้น
  • ปรับระดับความสว่างให้เหมาะสมกับการใช้งานแต่ละช่วงเวลา

ขั้นตอนการต่อวงจร

1 ไปที่ Draw -> Inputs and Sources -> Add Voltage Source
2 ไปที่ Draw -> Passive Components -> Add Potentiometer
3 ไปที่ Draw -> Outputs -> Add Lamp ต่อครบวงจรพร้อม Ground
วงจรที่ 2

วงจรกรองความถี่ต่ำ (RC Low-Pass Filter)

วงจรกรองสัญญาณที่ประกอบด้วยตัวต้านทาน (Resistor) และตัวเก็บประจุ (Capacitor) เพื่อลดทอนสัญญาณความถี่สูงและผ่านความถี่ต่ำ

ประโยชน์ของวงจร

  • กรองสัญญาณรบกวน (Noise) ย่านความถี่สูงออกจากระบบ
  • ใช้ในวงจรภาคจ่ายไฟเพื่อเรียงกระแสให้เรียบขึ้น
  • ประยุกต์ใช้ในระบบเครื่องเสียงและระบบสื่อสารโทรคมนาคม

ขั้นตอนการต่อวงจร

1 เพิ่มแหล่งจ่ายสัญญาณ AC: Draw -> Inputs and Sources -> Add AC Voltage Source
2 เพิ่มตัวต้านทานอนุกรม: Draw -> Passive Components -> Add Resistor
3 เพิ่มตัวเก็บประจุลงกราวด์: Draw -> Passive Components -> Add Capacitor
4 สังเกตสัญญาณกราฟ Output ขาออกเมื่อปรับความถี่ของแหล่งจ่าย AC
วงจรที่ 3

วงจรขยายสัญญาณทรานซิสเตอร์ (Transistor Common Emitter)

ใช้ทรานซิสเตอร์ (BJT) เป็นอุปกรณ์หลักในการขยายขนาดสัญญาณไฟฟ้าแรงดันต่ำให้มีแอมพลิจูดสูงขึ้น

ประโยชน์ของวงจร

  • ขยายสัญญาณไฟฟ้าอ่อนๆ เช่น จากไมโครโฟนหรือเซนเซอร์
  • ใช้เป็นพื้นฐานในภาคขยายเสียงและวงจรสวิตชิ่งอิเล็กทรอนิกส์
  • ควบคุมกระแสโหลดขนาดใหญ่ด้วยสัญญาณควบคุมขนาดเล็ก

ขั้นตอนการต่อวงจร

1 เพิ่มแหล่งจ่ายไฟ DC: Draw -> Inputs and Sources -> Add Voltage Source
2 เพิ่มทรานซิสเตอร์ NPN: Draw -> Semiconductors -> Add Transistor (NPN)
3 ต่อตัวต้านทาน Collector และ Base เพื่อไบอัสกระแสให้ทรานซิสเตอร์ทำงานในย่านแอคทีฟ
4 ป้อนสัญญาณอินพุตขนาดเล็กแล้ววัดแรงดันที่ขาออก (Collector)
วงจรที่ 4

วงจรตัวตั้งเวลา 555 Timer (Astable Multivibrator / ไฟกระพริบ LED)

ใช้งานไอซี 555 Timer ร่วมกับตัวต้านทานและตัวเก็บประจุ เพื่อสร้างสัญญาณพัลส์นาฬิกา (Clock Pulse) สำหรับขับไฟกระพริบ LED

ประโยชน์ของวงจร

  • สร้างสัญญาณพัลส์ความถี่คงที่สำหรับวงจรดิจิทัล
  • ใช้ทำไฟกระพริบเตือนภัย ไฟประดับ หรือสัญญาณนาฬิกา
  • ประยุกต์ควบคุมความเร็วรอบและระบบตั้งเวลาอัตโนมัติ

ขั้นตอนการต่อวงจร

1 เพิ่มแหล่งจ่ายไฟ DC และ Ground เพื่อเลี้ยงวงจร IC 555
2 ค้นหาและเพิ่ม IC 555 Timer: Draw -> Outputs/Chips หรือพิมพ์ค้นหาในระบบ
3 ต่อตัวต้านทานและตัวเก็บประจุที่ขา 2, 6 และ 7 เพื่อกำหนดคาบเวลาความถี่
4 ต่อหลอด LED เข้ากับขาออก (Pin 3) เพื่อสังเกตจังหวะการกระพริบ
วงจรที่ 5

วงจรเรียงกระแสแบบสะพาน (Bridge Rectifier Circuit)

ใช้วงจรไดโอด 4 ตัวต่อแบบบริดจ์ เพื่อแปลงกระแสไฟฟ้าสลับ (AC) ให้กลายเป็นกระแสไฟฟ้าตรง (DC) ทิศทางเดียวตลอดรอบสัญญาณ

ประโยชน์ของวงจร

  • แปลงไฟบ้าน AC 220V ให้เป็นไฟ DC สำหรับอุปกรณ์อิเล็กทรอนิกส์ทั่วไป
  • ใช้ประโยชน์จากกระแสทั้งซีกบวกและซีกลบอย่างคุ้มค่า
  • เป็นหัวใจหลักในอะแดปเตอร์และภาคจ่ายไฟ (Power Supply)

ขั้นตอนการต่อวงจร

1 เพิ่มแหล่งจ่ายไฟ AC: Draw -> Inputs and Sources -> Add AC Voltage Source
2 เพิ่มไดโอด 4 ตัว: Draw -> Semiconductors -> Add Diode
3 ต่อไดโอดเรียงเป็นวงจรบริดจ์ (Diamond Shape) เชื่อมต่อระหว่างแหล่งจ่าย AC และโหลดตัวต้านทาน
4 เพิ่มตัวเก็บประจุขนานที่โหลดเพื่อกรองแรงดันให้เรียบขึ้นแล้วสังเกตผลลัพธ์
วงจรที่ 6

วงจรแบ่งแรงดัน (Voltage Divider Circuit)

ใช้งานตัวต้านทานสองตัวต่ออนุกรมกันเพื่อแบ่งแรงดันไฟฟ้าจากแหล่งจ่ายหลักให้เป็นแรงดันย่อยตามสัดส่วนของค่าความต้านทาน

ประโยชน์ของวงจร

  • ลดระดับแรงดันไฟฟ้าให้เหมาะสมกับขาอินพุตของไมโครคอนโทรลเลอร์หรือเซนเซอร์
  • ใช้เป็นวงจรพื้นฐานในการอ่านค่าตัวต้านทานปรับค่าได้หรือ LDR
  • ออกแบบและคำนวณวงจรได้ง่ายด้วยกฎของโอห์ม

ขั้นตอนการต่อวงจร

1 เพิ่มแหล่งจ่ายไฟ DC: Draw -> Inputs and Sources -> Add Voltage Source
2 เพิ่มตัวต้านทาน 2 ตัวต่ออนุกรมกัน: Draw -> Passive Components -> Add Resistor
3 ต่อลง Ground และเชื่อมต่อจุดกึ่งกลางระหว่างตัวต้านทานทั้งสองเพื่อวัดแรงดัน Output
4 คลิกขวาที่ตัวต้านทานเพื่อเปลี่ยนค่าโอห์มและสังเกตการเปลี่ยนแปลงของแรงดันที่จุดกึ่งกลาง
วงจรที่ 7

วงจรกรองความถี่สูง (RC High-Pass Filter)

สลับตำแหน่งตัวเก็บประจุและตัวต้านทานในวงจรกรอง เพื่อให้สัญญาณความถี่สูงผ่านไปยังเอาต์พุตได้ดีในขณะที่ลดทอนสัญญาณความถี่ต่ำ

ประโยชน์ของวงจร

  • บล็อกสัญญาณ DC ที่ไม่ต้องการออกจากภาคขยายหรือโหลด
  • ใช้แยกสัญญาณเสียงแหลม (Tweeter) ในระบบเครื่องเสียง
  • ดึงเอาสัญญาณพัลส์หรือขอบสัญญาณฉับพลัน (Transient) ในระบบดิจิทัล

ขั้นตอนการต่อวงจร

1 เพิ่มแหล่งจ่าย AC: Draw -> Inputs and Sources -> Add AC Voltage Source
2 เพิ่มตัวเก็บประจุอนุกรมที่ทางเข้า: Draw -> Passive Components -> Add Capacitor
3 ต่อตัวต้านทานลง Ground ที่ขาออกเพื่อสร้างแรงดันตกคร่อม
4 ปรับเปลี่ยนความถี่ของแหล่งจ่าย AC ขึ้น-ลง แล้วสังเกตความแตกต่างของสัญญาณ Output บนกราฟ
วงจรที่ 8

วงจรออสซิลเลเตอร์ เฟสชิฟต์ (Phase Shift Oscillator)

ใช้ทรานซิสเตอร์ร่วมกับเครือข่าย RC เฟสชิฟต์เพื่อสร้างสัญญาณคลื่นไซน์ (Sine Wave) แบบออสซิลเลตเองโดยไม่ต้องมีอินพุตภายนอก

ประโยชน์ของวงจร

  • สร้างสัญญาณทดสอบความถี่เสียง (Audio Frequency Generator)
  • ใช้เป็นแหล่งกำเนิดสัญญาณอ้างอิงในเครื่องมือวัดอิเล็กทรอนิกส์
  • ศึกษาหลักการป้อนกลับเชิงบวก (Positive Feedback) และเงื่อนไขของเบิร์กเฮาเซน

ขั้นตอนการต่อวงจร

1 เพิ่มแหล่งจ่ายไฟ DC และทรานซิสเตอร์ NPN เป็นภาคขยายหลัก
2 เพิ่มเครือข่าย RC 3 ชุดต่ออนุกรมเพื่อหน่วงเฟสสัญญาณ 180 องศา: Draw -> Passive Components
3 ป้อนสัญญาณกลับจากเอาต์พุตเข้าสู่ขาเบส (Base) ของทรานซิสเตอร์ครบวงจร
4 รันการจำลองและสังเกตคลื่นไซน์ต่อเนื่องที่ปรากฏบนหน้าจอ Scope
วงจรที่ 9

วงจรเรกกูเลเตอร์แรงดันซีเนอร์ (Zener Diode Voltage Regulator)

ใช้ซีเนอร์ไดโอดรักษาแรงดันไฟฟ้าขาออกให้คงที่แม้ว่าแรงดันไฟเข้า (Input) หรือกระแสโหลดจะเปลี่ยนแปลงไป

ประโยชน์ของวงจร

  • ป้องกันอุปกรณ์อิเล็กทรอนิกส์จากแรงดันไฟกระชากหรือไฟเกิน
  • ให้แรงดันไฟเลี้ยง DC ที่เสถียรสำหรับวงจรไมโครคอนโทรลเลอร์และเซนเซอร์
  • โครงสร้างเรียบง่ายและต้นทุนต่ำในการรักษาเสถียรภาพแรงดัน

ขั้นตอนการต่อวงจร

1 เพิ่มแหล่งจ่ายไฟ DC แรงดันสูงกว่าซีเนอร์: Draw -> Inputs and Sources
2 เพิ่มตัวต้านทานจำกัดกระแสต่ออนุกรม และเพิ่มซีเนอร์ไดโอดต่อกลับขั้วลงกราวด์: Draw -> Semiconductors
3 ต่อโหลดตัวต้านทานขนานคร่อมกับซีเนอร์ไดโอดเพื่อดึงกระแสใช้งาน
4 ทดลองปรับค่าแหล่งจ่ายไฟเข้าแล้ววัดแรงดันตกคร่อมที่โหลดว่าจะคงที่ตามค่าซีเนอร์
วงจรที่ 10

วงจรเปรียบเทียบแรงดัน (Op-Amp Comparator / สวิตช์แสงอัตโนมัติ)

ใช้ไอซีขยายสัญญาณปฏิบัติการ (Operational Amplifier) ทำหน้าที่เปรียบเทียบแรงดันระหว่างอินพุตสองขาเพื่อตัดสินใจเปิด-ปิดรีเลย์หรือ LED

ประโยชน์ของวงจร

  • ประยุกต์ใช้ทำวงจรเปิดปิดไฟถนนอัตโนมัติตามแสงสว่าง (LDR Sensor)
  • ใช้เป็นวงจรตรวจจับอุณหภูมิหรือระดับน้ำในถัง
  • แปลงสัญญาณอนาล็อกให้เป็นสัญญาณดิจิทัล (High/Low) สำหรับไมโครคอนโทรลเลอร์

ขั้นตอนการต่อวงจร

1 เพิ่มแหล่งจ่ายไฟ DC คู่ (+V / -V) และ Op-Amp: Draw -> Active Components / Outputs/Chips
2 ต่อตัวต้านทานแบ่งแรงดันที่ขาไม่กลับเฟส (+) เพื่อกำหนดค่าแรงดันอ้างอิง (Threshold)
3 ต่อตัวต้านทานปรับค่าได้หรือ LDR ที่ขา (-) เพื่อรับสัญญาณอินพุตเซนเซอร์
4 ต่อหลอด LED ที่ขาออก (Output) แล้วปรับค่าสัญญาณอินพุตเพื่อดูจังหวะสลับสถานะติด/ดับ
